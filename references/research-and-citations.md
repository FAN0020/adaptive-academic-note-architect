# Evidence and targeted research

| Evidence class | Treatment |
|---|---|
| Source-derived | Faithful reformulation; course location where useful |
| Source-corrected | Material correction plus evidence, preserving valid teaching intent |
| Source-grounded explanation | Local “理解补充 / Explanation” where extending explicit content; verify inference |
| External supplement | “外部补充 / Supplement”; verify and cite substantive facts |
| Unverified | Attribute/qualify meaningful source claims; omit optional unsupported additions |

A blanket opening disclaimer is insufficient if readers cannot identify individual additions. Use compact local lead-ins/tags without labelling every routine sentence.

## Gap queue and priorities

Record question, purpose, priority, available evidence, required source and status (pending/verified/unresolved).

- P0: suspect definition, formula, central fact or conflict. Verify/correct or explicitly qualify before delivery.
- P1: prerequisite/mechanism essential to comprehension. Add a focused explanation and evidence for new facts.
- P2: optional trivia, surveys or adjacent methods. Skip unless requested. A date actually taught but uncertain is source verification, not optional trivia.

Group connected questions. Read supporting passages in primary papers, official documentation or authoritative textbooks, not only snippets/other summaries. Higher-priority browser requirements apply. Adequate supplied evidence can resolve a gap without a new search.

## Citation integrity

Map claim → source → page/section/URL → evidence class → scope. Reuse verified references. Place citations near substantive additions; numbered references work for long DOCX notes. Verify author/title/year when used and that the source supports the exact claim. Never invent DOI, URL, page, venue, quote, benchmark or citation count.

Distinguish teacher opinion, experience, hypothesis and established result. The transcript supports “the teacher reported X”, not X independently. An official business description does not verify an unnamed company, a market-share number or model configuration. Historical anecdotes require date alignment, not today's facts.

For grounded logical/mathematical explanation, verify reasoning and cite its starting point where useful. Notation clarification is not necessarily an external fact; a new theorem, result, research mechanism or historical claim requires evidence.

If a source is inaccessible, find another suitable source or retain uncertainty. Never mark unverified content verified. If browsing is prohibited, use provided evidence and disclose gaps. Stop when required questions are supported, corrected or qualified. Reopen research only for a concrete new conflict/claim/request. Link presence is machine-checkable; claim support needs substantive review.
